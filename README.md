## snugbit 
A virtual pet sim designed to teach kids responsibility and basic financial literacy with minigames and simple tutorials.

## Dependencies

This project requires the following Python packages:

- `pygame`
- `questionary`

Install them with:

```bash
pip install -r Reqiurements.txt
```
